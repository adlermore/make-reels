## 1. Cold B2B email — first touch  ⚠️ DRAFT

**Թեմա՝** Հարց Ձեր վաճառքի գործընթացի վերաբերյալ

```
Հարգելի՛ պարոն <Ազգանուն>,

Ես <Անուն Ազգանուն>ն եմ՝ <Ընկերություն> ընկերությունից։

Նկատեցի, որ Ձեր ընկերությունը վերջերս ընդլայնել է վաճառքի թիմը։ Մենք օգնում ենք նման ընկերություններին ավտոմատացնել հաճախորդների հետ աշխատանքը, և արդյունքում մենեջերները ձեռքով աշխատանքի վրա շաբաթական մինչև 5 ժամով պակաս ժամանակ են ծախսում։

Արդյո՞ք այս հարցը Ձեզ համար արդիական է։ Կարո՞ղ ենք այս շաբաթ 15 րոպե զրուցել։

Հարգանքով՝
<Անուն Ազգանուն>
<Պաշտոն>, <Ընկերություն>
<հեռախոս> | <էլ. փոստ>
```

Why it works: short, one reason for writing to this specific company, one concrete benefit, one easy question. No links, no attachments.

## 2. Cold email — follow-up  ⚠️ DRAFT

**Թեմա՝** Re: Հարց Ձեր վաճառքի գործընթացի վերաբերյալ

```
Հարգելի՛ պարոն <Ազգանուն>,

Վերադառնում եմ իմ նախորդ նամակին։ Հասկանում եմ, որ զբաղված եք, ուստի կլինեմ հակիրճ։

Եթե հաճախորդների հետ աշխատանքի ավտոմատացումը Ձեզ համար արդիական է, ուրախ կլինեմ ցույց տալ, թե ինչպես է դա աշխատում <նմանատիպ ընկերության օրինակ>-ում։

Եթե այս թեման Ձեզ չի հետաքրքրում, պարզապես պատասխանեք «ոչ», և ես այլևս չեմ գրի։

Հարգանքով՝
<Անուն Ազգանուն>
```

## 3. Meeting confirmation  ⚠️ DRAFT

```
Հարգելի՛ տիկին <Ազգանուն>,

Շնորհակալություն արագ պատասխանի համար։ Հաստատում եմ մեր հանդիպումը հոկտեմբերի 22-ին՝ ժամը 15:00-ին։

Հանդիպման ընթացքում կներկայացնեմ մեր լուծումը և կպատասխանեմ Ձեր հարցերին։ Եթե այդ ժամը Ձեզ հարմար չէ, խնդրում եմ տեղեկացնել, և ես կառաջարկեմ այլ տարբերակ։

Հարգանքով՝
<Անուն Ազգանուն>
```

## 4. UI strings  ⚠️ DRAFT

| English | Armenian |
|---|---|
| Log in | Մուտք գործել |
| Sign up | Գրանցվել |
| Forgot password? | Մոռացե՞լ եք գաղտնաբառը |
| Save | Պահպանել |
| Cancel | Չեղարկել |
| Delete | Ջնջել |
| Settings | Կարգավորումներ |
| Changes saved. | Փոփոխությունները պահպանված են։ |
| Something went wrong. Please try again. | Տեղի է ունեցել սխալ։ Խնդրում ենք կրկին փորձել։ |
| Are you sure? | Համոզվա՞ծ եք |

Buttons use the infinitive (Պահպանել), no final punctuation. Messages that are full sentences end with ։.

## 5. Common mistakes — wrong → right  ⚠️ DRAFT

| ❌ Wrong | ✅ Right | Why |
|---|---|---|
| Ինչպես եք? | Ինչպե՞ս եք։ | Question mark goes over the stressed vowel; sentence ends with ։ |
| Շնորհակալություն. | Շնորհակալություն։ | Armenian full stop ։, not Latin `.` |
| Շնորհակալություն: | Շնորհակալություն։ | Colon `:` is not a full stop; use ։ (U+0589) |
| Երեւան, նաեւ | Երևան, նաև | Reformed orthography uses the ligature և |
| Հարգելի պարոն | Հարգելի՛ պարոն | Vocative emphasis mark in formal address |
| Մենք հանդիսանում ենք առաջատար ընկերություն | Մենք առաջատար ընկերություն ենք | «հանդիսանալ» is a calque of Russian «являться» |
| Ընդունել որոշում | Որոշում կայացնել | Calque of «принять решение» |
| "Logix" | «Logix» | Armenian quotation marks |
| ձեր (to a client in a letter) | Ձեր | Formal address is capitalized in letters |
