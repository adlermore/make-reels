# SPEC: AI Reels Production Studio

Исходное ТЗ: master prompt пользователя (2026-11-04). Здесь собраны требования **с учётом принятых решений**. Этот файл нужно перечитывать после сжатия контекста или в новой сессии.

## Решения пользователя (приоритет выше исходного ТЗ)
1. **Только бесплатно и локально. Внешние API не подключать.** Генерация выполняется из терминала: творческую часть делают агенты Claude Code, а медиа создаёт локальный код.
2. Для данных при необходимости используется БД. Выбран `node:sqlite` (`data/studio.db`).

## Цель
По теме и краткому Content Brief команда агентов производит Instagram Reels от идеи до готового MP4:
`One Topic → Research → Creative Concept → Script → Storyboard → Assets → Video Production → Sound Design → Editing → QC → Final Reels`.

## Обязательные свойства
- 8 субагентов: trend-researcher, creative-director, scriptwriter, storyboard-director, asset-producer, motion-designer, sound-designer, quality-controller. У каждого своя роль, минимум инструментов и контракт входа и выхода.
- Скиллы: `/create-reel` (главный), research-trends, create-storyboard, quality-check.
- Гейты A (концепция), B (ассеты и аниматик, вместо «платной генерации»), C (превью), D (финал). Без согласия пользователя они не проходятся. Автопубликации нет.
- Стандарт: 9:16, 1080×1920, 30 fps, H.264 yuv420p + faststart, AAC 48 кГц стерео, −14 LUFS, TP ≤ −1 dBTP. Длительность 15, 30, 45, 60 секунд или своя.
- Субтитры с подсветкой текущего слова и ключевых слов, кириллические шрифты, настраиваемые безопасные зоны (250 / 420 / 60 / 140 px).
- Бренд-система с несколькими брендами и снимком бренда внутри проекта.
- Учёт расходов: таблица `costs` и файл `production-cost-report.json`. В локальном режиме везде $0, но механизм готов.
- Состояние переживает перезапуск. Хеши входов исключают повторную генерацию одного и того же.
- QC на 100 баллов: проходной балл 90, критические ошибки блокируют. Автоматические проверки отделены от экспертной оценки.
- Итоговые материалы: research-report.md, creative-direction.md, script.md, storyboard.md, shot-list.json, asset-manifest.json, sound-design-plan.md, production-cost-report.json, quality-report.md, final.mp4, preview.mp4, poster.png, subtitles.srt, README.md, а также final-no-music.mp4 и publish-kit.md.

## Принятые технические решения
| Тема | Решение | Почему |
|---|---|---|
| Видео-движок | Remotion 4.0.540, React 19, TypeScript 5.9 | программный монтаж, повторно используемые компоненты |
| Визуал | моушн-дизайн, кинетическая типографика, инфографика, SVG с анимацией прорисовки, свои материалы пользователя | бесплатно; GPU GT 730 не тянет локальную генерацию нейросетями |
| Голос | Piper 1.8 (`.venv`), SAPI как резерв, запись пользователя | офлайн и бесплатно; Piper даёт точные тайминги слов |
| Музыка и SFX | собственный DSP на TypeScript | оригинально, детерминировано, без лицензионных рисков |
| Сведение | FFmpeg: sidechain-дакинг и двухпроходный loudnorm | измеримые целевые значения |
| БД | `node:sqlite` | без зависимостей и без сервера |
| Монтаж | сначала аудио: окна сцен берутся из реального голоса | рассинхрон голоса и видео исключён по построению |

## Известные ограничения
- Фотореалистичные «киношные» AI-кадры в бесплатном режиме не генерируются. Вместо них используются моушн-дизайн и SVG. Свои видео и фото можно положить в `assets/local/`.
- Коммерческое использование голосов Piper не подтверждено (см. docs/SETUP.md). Чистый вариант — собственная запись (`recorded`).
- Агенты и скиллы, созданные в сессии, видны Claude Code только после её перезапуска.
- Шрифты Google загружаются при рендере, нужен интернет.
