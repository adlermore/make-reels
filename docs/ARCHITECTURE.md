## Слои
| Слой | Где | Что делает |
|---|---|---|
| Оркестрация | главная сессия + `.claude/skills/create-reel` | порядок этапов, делегирование, гейты, повторные попытки |
| Специалисты | `.claude/agents/*.md` (8 субагентов) | творческие решения и файлы-контракты |
| Контракты | `src/types/schemas.ts` | Brief, Script, ShotList, VoiceTiming, Timeline, Brand, Asset — zod-схемы, общие для агентов, CLI и движка |
| Исполнение | `pipeline/` | детерминированные шаги, повторяемые, с хешами входов |
| Видео-движок | `src/` (Remotion 4, React 19) | одна мастер-композиция `Reel`, которая рендерит любой `timeline.json` |
| Состояние | `data/studio.db` + JSON-зеркала в проекте | восстановление после перезапуска, история, стоимость, QC |

## Медиа-конвейер (audio-first)
1. **Озвучка первой**: сценарий → Piper синтезирует сцену за сценой → реальные длительности + тайминги слов.
2. Если суммарная длина отличается от брифа больше чем на 6%, темп речи подгоняется (быстрее до ×1,14, медленнее не дальше естественного темпа). Если этого не хватает, выдаётся требование сократить сценарий.
3. **Окна сцен** вычисляются из голоса: склейка за 0,12 с до начала фразы сцены. CTA держится 1,6 с после последнего слова.
4. Музыка генерируется точно под длину. SFX расставляются по склейкам и событиям: hook, пункты списка, статистика, CTA.
5. Сведение: дакинг музыки под голос через sidechain, двухпроходный loudnorm до −14 LUFS / TP −1,5.
6. `timeline.json` складывается из раскадровки, голоса и бренда. Переходы центрируются на склейке (`src/utils/timing.ts`).
7. Remotion рендерит H.264/yuv420p/AAC 48 кГц с faststart. Отдельно делаются версия без музыки, постер и SRT.

## Языки
- Язык ролика задаётся в брифе (`hy` по умолчанию, `ru`, `en`) и попадает в `timeline.json`. Движок берёт из него типографику (`src/utils/typography.ts`), формат чисел и подписи интерфейса (`src/utils/i18n.ts`).
- Шрифты: к любому шрифту бренда автоматически подключается Noto Sans Armenian (`src/utils/fonts.ts`).
- Голос выбирается по языку (`brand.voice.piperVoiceByLanguage`).
- Армянский текст проверяет линтер `pipeline/lib/lint-hy.ts`. Отчёт QC и README проекта генерируются на языке ролика (`pipeline/lib/report-i18n.ts`).

## Устойчивость и повторяемость
- Каждая команда хеширует свои входы. Если ничего не изменилось, этап пропускается, и утверждённые материалы не генерируются заново.
- Изменение входного артефакта помечает все последующие этапы `stale`, и утверждения перестают действовать.
- Запись файлов атомарная: сначала tmp, потом rename. Прерванный запуск не оставляет полу-JSON.
- Ошибка этапа пишется в БД как `failed` с текстом и подсказкой. `status` показывает, с какого места продолжать.
- Синтез детерминирован: одинаковый seed даёт одинаковую музыку и SFX.

## Расширение
- **Новый бренд**: `brands/<id>/brand-config.json`, затем `init <project> --brand <id>`.
- **Новый layout**: компонент в `src/components/layouts/Scenes.tsx`, значение в `LAYOUTS` (schemas), правило в `validate.ts`, описание у storyboard-director.
- **Новый голосовой движок**: класс `VoiceEngine` (`pipeline/providers/interfaces.ts`) и регистрация в `pickVoiceEngine`.
- **Платные провайдеры в будущем**: см. `docs/API-INTEGRATIONS.md`. Там проверенные факты и обязательные предохранители.
