# Внешние API

## Текущее решение: внешние API не подключены
По решению пользователя система работает **только бесплатно и локально**. Код не делает ни одного платного запроса, и API-ключи не нужны.

| Задача | Чем делается сейчас (бесплатно) |
|---|---|
| Визуал | Remotion: моушн-дизайн, кинетическая типографика, инфографика, SVG-иллюстрации от asset-producer, твои видео и фото из `assets/local/` |
| Голос | Piper (нейросетевой офлайн TTS), Windows SAPI или твоя запись |
| Музыка | Процедурный синтезатор `pipeline/audio/music.ts` или твой трек с записью о лицензии |
| SFX и эмбиент | Процедурный синтез `pipeline/audio/sfx.ts` |
| Сведение и QC | FFmpeg / FFprobe |

### Бесплатный способ добавить сгенерированные кадры
В раскадровке у каждой сцены есть `imagePrompt`, `videoPrompt` и `negativePrompt`. Их можно вручную вставить в любой бесплатный веб-генератор. Результат положи в `projects/<id>/assets/local/`, запиши его происхождение в `assets/local/LICENSES.md` и укажи в сцене `background.source: "local-image"` или `"local-video"`.

## Если в будущем понадобятся платные провайдеры
Ниже факты из официальной документации, проверенные 2026-11-04. Перед подключением перепроверь их: цены и модели меняются.

### Обязательные предохранители (реализовать до первого платного вызова)
1. Отдельное решение пользователя и новый гейт «Generation Approval»: что генерируется, где, сколько раз и за какую сумму.
2. Лимит бюджета в коде: платный вызов невозможен без `approvals.json` с суммой, и прогноз стоимости не может превышать остаток.
3. Перед повторной отправкой задача сначала проверяется по сохранённому `taskId`, а не создаётся заново.
4. Ключи только в `.env`, который уже в `.gitignore`. Чтение `.env` для Claude запрещено правилом deny.
5. Каждая генерация записывается в таблицу `costs` (провайдер, модель, операция, единицы, прогноз и факт).

### Runway Developer API
- Base `https://api.dev.runwayml.com`. Заголовки `Authorization: Bearer <key>` и обязательный `X-Runway-Version: 2024-11-06`.
- Генерация: `POST /v1/image_to_video`, `POST /v1/text_to_video`, `POST /v1/text_to_image`, возвращают `{id}`. Статус: `GET /v1/tasks/{id}` (PENDING, THROTTLED, RUNNING, SUCCEEDED, FAILED, CANCELLED). Отмена: `DELETE /v1/tasks/{id}`.
- Ссылки на результат живут 24–48 часов, файлы нужно сразу скачивать.
- Вертикаль 1080×1920: veo3.1, kling3.0_pro, seedance2/2_5, wan3. Модели gen4.5 и gen4_turbo дают только 720:1280.
- Цена: 1 кредит = $0.01. Например, gen4_turbo стоит 5 кредитов в секунду, gen4.5 — 12/с, kling3.0_pro — 12/с, gen4_image — 5–8 кредитов за картинку.
- Ответ модерации приходит как FAILED, но всё равно оплачивается.
- Есть официальный SDK `@runwayml/sdk`.

### ElevenLabs
- Заголовок `xi-api-key`. TTS с таймингами: `POST /v1/text-to-speech/{voice_id}/with-timestamps` возвращает `audio_base64` и выравнивание по символам.
- Русский поддерживают `eleven_multilingual_v2`, `eleven_v3` и `eleven_v4`. SFX: `POST /v1/sound-generation` (передавай `eleven_text_to_sound_v3`, версия v2 устаревает). Музыка: `POST /v1/music`. Выравнивание по готовому аудио: `POST /v1/forced-alignment`.
- Цена API: TTS около $0.08 за 1000 символов (v4, v3, Multilingual v2), SFX $0.12 за минуту, музыка $0.15 за минуту.
- **Бесплатный тариф не разрешает коммерческое использование.**

### fal.ai (агрегатор: Kling, Seedance, Veo, FLUX и другие)
- Очередь: `POST https://queue.fal.run/{model_id}` с заголовком `Authorization: Key <key>`. Возвращает `request_id`, `status_url` и `response_url`.
- Kling v4 image-to-video стоит около $0.235 за секунду в 1080p. Veo 3.1 на fal **будет отключён 17.11.2026**.

### Как добавить провайдера
1. Опиши интерфейс по аналогии с `pipeline/providers/interfaces.ts`: submit, poll, download и cost.
2. Сделай реализацию в `pipeline/providers/<kind>/<name>.ts`, с таймаутами, повтором на 429/5xx с экспоненциальной задержкой, без повтора на 400/401/402, и сохраняй `taskId` в БД до начала опроса.
3. Добавь Mock-реализацию для тестов.
4. Сначала реализуй предохранители из списка выше.
