## Точка продолжения
Если ты Claude Code на другом компьютере, начни с `npm run reel -- status ai-business-hy`.

**Армянский тестовый ролик `projects/ai-business-hy`** (по полному конвейеру агентов):
1. ✔ research → ✔ creative → ✔ script (57 слов, валидатор без замечаний) → storyboard (раскадровщик работал на момент коммита; проверь `npm run reel -- validate ai-business-hy storyboard`).
2. Дальше: агент **asset-producer** рисует SVG из «Illustration requests» в `storyboard/storyboard.md` → `npm run reel -- illustrations ai-business-hy` → `validate`.
3. **Этап A:** показать пользователю армянский сценарий + русский перевод каждой сцены и спросить утверждение (B–D для этого тестового ролика пользователь не предразрешал — спросить).
4. `produce ai-business-hy assets` → (B) → `produce … preview` → (C) → `render … --final` → агент **quality-controller** → (D) → `deliver` → publish-kit.md на армянском → commit + push.
